🚀 Đưa Web này lên GitHub Pages trong 2 phút

Không cần cài phần mềm lập trình. Làm trực tiếp trên trình duyệt điện thoại hoặc máy tính:

Bước 1: Tạo Repository trên GitHub

Vào github.com → Bấm dấu + (góc trên phải) → chọn New repository → Đặt tên b1-104-vstep → Chọn Public → Bấm Create repository.

Bước 2: Tải file index.html lên

Trong trang Repo vừa tạo, bấm uploading an existing file → Chọn file index.html bạn vừa tải về → Bấm nút xanh Commit changes.

Bước 3: Bật link Web & Cài vào Điện thoại

Vào tab Settings → Pages → Mục Branch chọn main → Save. Sau 30 giây bạn có link web chạy mọi nơi! Trên điện thoại bấm Chia sẻ → Thêm vào MH chính.
